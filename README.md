# PlanProjekt — web beta

«Диктофон для вайбкодинга»: on the go, an idea or a bug for one of my projects —
text and a picture; at home a Claude Code session in that project sees it.

This repository holds only the **web interface prototype** (stage 2): it keeps
entries in the browser (IndexedDB) and sends nothing. Entries never live here.
